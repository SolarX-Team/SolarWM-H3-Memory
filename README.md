# SolarWM H3 + Memory

[Read the blog](https://solarx-team.github.io/SolarWM-H3-Memory/) · [中文](https://solarx-team.github.io/SolarWM-H3-Memory/zh.html)

Training Memory For Video World Model Is Easier Than You Think.

This repository contains the bilingual static blog and its public media assets. GitHub Pages serves the `main` branch from the repository root.

## Local preview

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/` (English) or `http://localhost:8000/zh.html` (Chinese).

## Media

Videos use H.264 web encoding at their original spatial resolution and frame rate. The long-rollout videos show the full 180-second sequences at 4× speed, as labeled on the page. Revisit stills retain their full resolution.
